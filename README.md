# Sonsuz Çay Demleme Makinesi

## Bilimsel Devrim ve Absürt Ciddiyet

Bu repository, insanlık tarihinin en önemli icatlarından birini temsil eder: **Sonsuz Çay Demleme Makinesi**.

Yıllar süren (şaka) araştırmalar sonucunda, çay demlemenin aslında bir sonsuz döngü olduğu ve bu döngünün asla kırılmaması gerektiği keşfedilmiştir. Bu kod, o döngüyü simüle eder. Gerçekten çalışır. Sonsuza kadar. (Ctrl+C'ye basana kadar.)

### Özellikler
- Gerçekten sonsuz `while True` döngüsü
- Rastgele absürt olaylar (çay taşması, kedi oturması, elektrik kesintisi)
- Sahte sıcaklık takibi
- Bilimsel görünüm ama tamamen uydurma

### Kurulum ve Çalıştırma
```bash
python3 cay_demle.py
```

Makineyi durdurmak için `Ctrl+C`. Ama neden durdurasınız ki? Çay demlemek evrenin görevidir.

### Bilimsel Kanıt
Çay, evrenin temel yapı taşıdır. Bu makine olmadan evren çöker. (Kaynak: Yok.)
